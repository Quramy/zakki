## Chrome 157 beta

SVG Path Data API というものの存在を mozaic.fm で知った。
https://chromestatus.com/feature/4787972240179200?gate=6208960626556928

逆に今までなかったんか、という気もする。Safari 系には独自実装で似たようなことができる API があるらしい。
